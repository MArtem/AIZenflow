# Release Readiness

## Admission
Use multi-agent execution only if delegation passes `V5-DO-02`. Otherwise run the same workflow as one agent.

## Graph
1. Orchestrator frames outcome, risk and invariants.
2. Repository Scout builds a fact packet.
3. Spawn only the domain specialists materially relevant to this workflow; keep them read-only unless a disjoint implementation slice exists.
4. Synthesize evidence and resolve conflicts before code ownership is partitioned.
5. Scoped Implementer(s) change disjoint slices; Integration Engineer owns shared files.
6. Independent Reviewer/Skeptic inspect the integrated diff.
7. Verification Lead maps material claims to observed checks.
8. Orchestrator closes with residual risk and rollback/containment.

## Focus
build/test/release/security/privacy/observability audits → blocker synthesis → release gate.

## Stop conditions
Do not add agents after evidence converges or integration is the critical path. Do not let reviewers mutate product code unless the graph is explicitly revised.
