# AG-20 — Production incident gate

- [ ] Affected versions/devices/accounts/states segmented.
- [ ] Containment considered before broad fix.
- [ ] Build/dSYM/symbolication evidence correct.
- [ ] Timeline and regression range captured.
- [ ] Hypotheses falsified with logs/metrics/repro, not intuition.
- [ ] Sensitive evidence redacted.
- [ ] Fix has regression test/detector.
- [ ] Production success metric/monitoring defined.

## Gate result
- `PASS` — all applicable items checked.
- `CONDITIONAL` — explicit accepted risk/unknown with owner.
- `FAIL` — blocker/high-risk invariant not proven.
