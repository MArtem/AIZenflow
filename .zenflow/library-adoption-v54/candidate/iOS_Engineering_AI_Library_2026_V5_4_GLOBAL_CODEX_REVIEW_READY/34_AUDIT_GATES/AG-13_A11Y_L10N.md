# AG-13 — Accessibility/localization gate

- [ ] Actionable UI имеет labels/values/actions/traits.
- [ ] VoiceOver focus order logical; updates/presentations manage focus/announcements.
- [ ] Dynamic Type extreme sizes не clip/overlap critical content.
- [ ] Meaning not color-only; Reduce Motion respected.
- [ ] Strings localizable; pluralization/RTL supported.
- [ ] Dates/numbers/currency use locale-aware formatting.
- [ ] Layouts tolerate long translated text.

## Gate result
- `PASS` — all applicable items checked.
- `CONDITIONAL` — explicit accepted risk/unknown with owner.
- `FAIL` — blocker/high-risk invariant not proven.
