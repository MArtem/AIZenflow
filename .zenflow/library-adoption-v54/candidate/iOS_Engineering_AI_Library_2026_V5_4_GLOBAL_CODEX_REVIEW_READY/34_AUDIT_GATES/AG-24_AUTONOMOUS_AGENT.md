# AG-24 — Autonomous coding-agent gate

- [ ] Agent read repository instructions before edits.
- [ ] Facts and assumptions separated.
- [ ] Risk class/invariants recorded.
- [ ] No destructive/security-relaxing shortcut.
- [ ] All changed files inside requested scope or explained.
- [ ] Build/test claims backed by observed output.
- [ ] Final diff reviewed by agent.
- [ ] Verified/Reasoned/Unknown ledger present.
- [ ] R3+ changes left with human-review/rollback boundary.

## Gate result
- `PASS` — all applicable items checked.
- `CONDITIONAL` — explicit accepted risk/unknown with owner.
- `FAIL` — blocker/high-risk invariant not proven.
