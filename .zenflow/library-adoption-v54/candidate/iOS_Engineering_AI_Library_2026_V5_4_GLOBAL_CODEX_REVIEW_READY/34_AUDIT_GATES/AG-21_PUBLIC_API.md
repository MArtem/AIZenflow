# AG-21 — Public/package API gate

- [ ] API surface minimal and names/types express semantics.
- [ ] Source compatibility impact checked.
- [ ] Generic/protocol/opaque/existential choice justified.
- [ ] Error and ownership semantics documented.
- [ ] Objective-C/C or binary clients considered if relevant.
- [ ] Availability annotations fit deployment/package promise.
- [ ] Semver/changelog/migration guidance included when breaking.

## Gate result
- `PASS` — all applicable items checked.
- `CONDITIONAL` — explicit accepted risk/unknown with owner.
- `FAIL` — blocker/high-risk invariant not proven.
