# Synthesis Protocol

Synthesis preserves distinctions between findings.

1. Normalize claims into the evidence ledger.
2. Deduplicate only semantically identical claims.
3. Keep conflicting claims side-by-side until resolved.
4. Group by invariant/risk boundary, not by agent name.
5. Prefer evidence-backed minimal decisions over consensus language.
6. Mark rejected recommendations with the reason and evidence.
7. Produce one integrated plan with explicit owner and verification for each action.

Never summarize disagreement away.
