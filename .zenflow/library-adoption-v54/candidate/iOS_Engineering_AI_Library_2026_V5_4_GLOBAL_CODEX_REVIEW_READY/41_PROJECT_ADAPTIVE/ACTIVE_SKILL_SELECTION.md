# Active Skill Selection

Always include repository intake, task routing, implementation, review, testing and change planning. Add domain skills based on observed technologies and risk boundaries. Examples:
- SwiftUI signal → `ioslib-swiftui`
- UIKit signal → `ioslib-uikit`
- Swift concurrency constructs → `ioslib-swift-concurrency`
- Core Data / SwiftData / Realm / GRDB → persistence and migration skills
- auth/session terms → `ioslib-networking-auth` + security/privacy
- StoreKit → `ioslib-storekit`
- App Intents → `ioslib-app-intents`
- widgets/extensions/background → `ioslib-background-execution` and system integrations

Skill selection is a routing optimization, not permission to ignore a relevant skill merely because it was not auto-selected.
