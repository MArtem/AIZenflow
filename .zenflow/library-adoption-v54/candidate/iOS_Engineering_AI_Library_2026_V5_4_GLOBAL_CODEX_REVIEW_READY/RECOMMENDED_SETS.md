# Recommended Sets — Hardened Global Edition

## Every client write task
1. `$ioslib-client-code-protection`
2. narrow domain skill (`$ioslib-implementation`, `$ioslib-swift-concurrency`, `$ioslib-networking-auth`, etc.)
3. `$ioslib-safe-command-execution` before uncertain commands
4. protection verification + task-specific build/tests

## New/unfamiliar repository
`$ioslib-repo-intake` + `$ioslib-project-adaptation` + `$ioslib-client-code-protection` before any write.

## R3/R4 change
Add `$ioslib-change-plan`, bounded `$ioslib-delegation-planner`/`$ioslib-multi-agent-orchestrator`, one integration owner, independent verification and protected-path review.
