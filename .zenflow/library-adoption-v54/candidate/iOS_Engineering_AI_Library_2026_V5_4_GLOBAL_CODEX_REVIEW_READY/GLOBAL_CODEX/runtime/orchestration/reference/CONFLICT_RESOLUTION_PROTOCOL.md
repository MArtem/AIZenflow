# Conflict Resolution Protocol

When specialists disagree:
1. State the exact conflicting claims.
2. Identify the invariant/requirement that decides the issue.
3. Compare evidence freshness and strength.
4. Inspect the narrowest missing repository fact.
5. If still unresolved, run a targeted experiment/test or assign one read-only arbiter with a precise question.
6. Escalate to the user only when the decision is a product/business preference, destructive boundary, or cannot be resolved from available evidence.

Do not use majority vote, role seniority, verbosity or model identity as tie-breakers.
