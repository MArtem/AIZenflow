# Legacy Documentation Process Audit

> **Historical record.** This audit predates the current governed baseline and is retained for
> provenance. Its “safe target state” rows are not current instructions; use
> `documentation-system-audit.md`, the canonical router, and the current baseline instead.

## Scope
Read-only classification of legacy sync tooling, generated inventories, saved prompts,
external-environment snapshots, baseline transfer references, and canonical CI state.

## Classification

| Asset | Classification | Evidence / Risk | Safe target state |
|---|---|---|---|
| `scripts/sync_from_worktrees.py` | dangerous legacy tooling | Uses obsolete checkout roots and deletes `reusable/`, `apps/`, and `tasks/` before copying. | Never run in the current checkout. Add a fail-closed retirement guard or archive it only in a separately approved migration. |
| `MANIFEST.md`, `inventory.json`, `reusable/MANIFEST.md`, `ALL_DOCUMENTS_INVENTORY.md` | provenance/reference snapshots | Generated by the dangerous legacy sync and already omit active durable files; current checks validate stale entries but not complete coverage. | Replace with a non-destructive manifest generator and bidirectional freshness check before treating them as active inventories. |
| `reusable/baseline/REUSABLE_MANIFEST.md` | active legacy bootstrap manifest | Still references old `documentation-split` transfer paths and mixes current and historical bootstrap assumptions. | Migrate to the baseline mirror/overlay policy plus an explicit minimal bootstrap manifest. |
| `reusable/baseline/scripts/install_reusable_baseline.sh` and `sync_reusable_baseline_to_project.sh` | active legacy bootstrap tooling | Bulk-copies baseline trees and external-environment snapshots; it does not use the new drift policy and can overwrite local docs. | Replace with plan/apply phases, explicit overlay handling, and opt-in provenance snapshot copying. Do not run automatically. |
| `reusable/baseline/NEW_PROJECT_PORTING_GUIDE.md` and `TRANSFER_CHECKLIST.md` | active legacy process docs | Direct users to old `documentation-split` paths and default snapshot copying. | Update only with the bootstrap-tool migration above so docs and behavior change together. |
| `reusable/saved-prompts/` | provenance/reference | README identifies exact Codex app exports and places current project/task rules above them. | Preserve; load only when a saved-prompt task explicitly requires it. |
| `reusable/baseline/external-environment/` | provenance/reference | 270 tracked files (~2.7 MB) snapshot external skills/tooling; not needed for normal startup. | Keep canonical for recovery/reference; make copying into worktrees opt-in. |
| Canonical CI | backlog | No `.github/workflows` or other CI configuration exists. Some gates require an active worktree or second checkout. | After CLI stabilization, add a separately reviewed docs-only workflow for canonical-local checks; exclude remote-state and live-worktree drift checks. |

## Current Safe Decision
- Do not run, move, delete, or auto-rewrite any legacy/provenance asset in this block.
- The new resolver, context-cost report, and drift validator are read-only.
- Generated snapshot incompleteness remains explicit backlog; it is not a completion claim.
