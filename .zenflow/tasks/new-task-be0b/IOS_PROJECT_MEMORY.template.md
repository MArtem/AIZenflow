# Project memory skeleton

Document contract version: 1. Human template; no runtime parser or machine validation claim.
Use after authorized exact-project association under
[iOS project workflow](../docs/IOS_PROJECT_WORK_SYSTEM.md). Adapt existing app records;
do not create all sections as separate files. Keep only relevant fields for a small task.
Maintenance owner: app documentation owner; refresh on dependent source/authority changes.
Place instantiated memory under the selected app boundary, not reusable or another app.
Replace template links with canonical links appropriate to that app's actual location.
