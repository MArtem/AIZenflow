# UI / Accessibility / Localization Checklist

- [ ] State owner and source of truth are clear.
- [ ] View/model identity is stable.
- [ ] Loading/error/empty states handled where relevant.
- [ ] User-facing strings localized.
- [ ] Dates/numbers/plurals locale-aware.
- [ ] Long text/Dynamic Type does not clip.
- [ ] Semantic controls/labels/values/actions are accessible.
- [ ] Color is not the sole meaning carrier.
- [ ] Significant custom motion respects Reduce Motion.
- [ ] RTL/long-localization layout considered.
- [ ] Accessibility Inspector/manual checks performed according to risk.
