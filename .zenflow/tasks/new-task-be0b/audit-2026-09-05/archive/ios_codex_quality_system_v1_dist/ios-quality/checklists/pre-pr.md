# Pre-PR Checklist

- [ ] Pre-commit gates complete.
- [ ] Full relevant test plan run when required.
- [ ] R3+ reproducibility/clean-state verification performed.
- [ ] Dependency resolution stable and reviewed.
- [ ] Migration/backward compatibility tested when applicable.
- [ ] Security/privacy/accessibility/localization gates complete.
- [ ] UI evidence attached when useful.
- [ ] PR explains risk, tests, residual uncertainty and rollback.
- [ ] Human approvals/signoff requested for consequential changes.
