# Pre-Change Checklist

- [ ] Relevant instructions/profile read.
- [ ] Git status/pre-existing changes understood.
- [ ] Existing implementation and tests inspected.
- [ ] Acceptance criteria written.
- [ ] Risk R0-R5 assigned.
- [ ] Trigger tags assigned.
- [ ] Relevant policies loaded.
- [ ] State ownership/invariants understood.
- [ ] Concurrency lifetime/cancellation defined if applicable.
- [ ] Persistence/security/privacy/dependency impact assessed.
- [ ] Test strategy defined before editing.
- [ ] Required human approvals obtained.
