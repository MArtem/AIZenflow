# Pre-Commit Checklist

- [ ] Affected scheme/target builds.
- [ ] Targeted tests pass.
- [ ] Required specialist gates pass.
- [ ] No new unexplained warnings/runtime issues.
- [ ] Final diff reviewed line by line.
- [ ] No unrelated cleanup/formatting.
- [ ] No accidental project/dependency/entitlement/privacy changes.
- [ ] No secrets/local paths/build artifacts.
- [ ] Tests were not weakened to make implementation pass.
- [ ] Risky constructs have written justification.
- [ ] Verification report is truthful about unverified areas.
