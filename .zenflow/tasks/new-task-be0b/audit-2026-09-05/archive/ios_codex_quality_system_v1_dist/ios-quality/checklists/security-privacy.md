# Security / Privacy Checklist

- [ ] No secrets/tokens/passwords/private keys in source/logs.
- [ ] Sensitive persistence uses appropriate storage.
- [ ] ATS not weakened without approval.
- [ ] Auth refresh/logout/revocation/concurrency reviewed.
- [ ] External URLs/input validated.
- [ ] Permissions requested only when required and purpose strings accurate.
- [ ] Privacy manifest reviewed for required-reason APIs/data use.
- [ ] Third-party SDK privacy/signature requirements checked.
- [ ] Cryptography uses standard platform primitives/protocols.
- [ ] Logs use privacy redaction and avoid sensitive bodies.
- [ ] New dependency passed supply-chain review.
