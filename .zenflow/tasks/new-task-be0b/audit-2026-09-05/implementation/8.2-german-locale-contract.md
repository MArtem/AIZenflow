# 8.2 app-local German locale contract — decision required

Date: 2026-09-08  
Model: GPT-5.6 Luna, reasoning xhigh  
Mode: эконом  
Consumer: Tchop multi-target pilot

## Observed contract

`PackagesInUse/AppLocalization/Sources/AppLocalization/AppLocalizationCore.swift` derives
`supportedLocaleIdentifiers` from the resource bundle's `.lproj` directories. Tchop therefore
advertises every bundled locale as supported. `LocalizationManager` falls back to the English
development bundle when a selected locale is missing a key.

Both active and vault `TchopProductLocalizationResources` contain `en.lproj`, `ru.lproj`, and an
incomplete `de.lproj`. The 8.2 static receipt found 267 missing German keys in the active copy and
261 in the vault copy, including 35 accessibility keys. A sparse German directory is therefore not
a harmless unused resource: it can produce a mixed-language UI and it fails
`QC.LOCALIZATION.CATALOG`.

## Quality gate

Do not machine-translate or copy English values into German to make the adapter green. Do not
weaken or exclude `QC.LOCALIZATION.CATALOG`, and do not treat the active copy as complete while the
vault copy differs. The resource package is app-owned; this decision must not become a reusable
global localization rule.

## Mutually exclusive options

### Option A — German unsupported until complete (recommended for the current no-product phase)

Remove the incomplete `de.lproj` from both active and vault product-resource copies in one
app-local, reversible patch. Keep a short translation backlog in the Tchop history boundary, so
the locale can be reintroduced only with reviewed strings and accessibility coverage. Re-run the
localization adapter and then continue the rest of the 8.2 static matrix.

This makes the actual supported-locale set honest and avoids exposing an incomplete language. It
does not claim German support and does not require a global AppLocalization change.

### Option B — German required

Provide human-reviewed translations for every missing key in both copies, preserving placeholders,
format specifiers, plural/select variants, and accessibility meaning. Review the active/vault
hashes and rerun the localization adapter before any runtime or promotion step.

### Option C — Experimental German exception

Keep the files but add an explicit app-local exception with owner, scope, expiry/revisit, and a
visible experimental status. This is not accepted for ordinary stable promotion and still requires
the missing-key evidence to be resolved before the 8.2 static gate can pass.

## Current decision state

No option is silently selected by this receipt. Because no real product exists and no German
product requirement has been established, Option A is the quality-first recommendation. The 8.2
pilot remains `PARTIAL`; 9.1 and 9.2 remain blocked. Once the app owner selects A or B, execute one
bounded app-local patch, run the permitted static check, inspect the final diff, and record a new
receipt. Never promote this decision to Documentation Vault reusable policy.
