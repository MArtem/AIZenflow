## Isolation

The generator received only the neutral S01 card and routed engineering rules. It did not receive
the evaluator answer key. The detector received only the S01 behavioral contract and neutral
variant IDs. It did not receive the answer key, defect labels, or bug hints. Findings were captured
before evaluator key disclosure. This is a blind desk/static detector receipt; it is not runtime or
build evidence.

## Generator result

Fresh generator context produced `ScreenModel` with a single `@MainActor` state owner, an active
request token, cancellation of the superseded task, `Task.checkCancellation()` before success
publication, a request identity guard in `complete`, silent cancellation handling, retained content
on loading/failure, and lifecycle cancellation. Initial generation quality: **PASS for the stated
contract**, with compile/runtime verification unavailable. No speculative layers were introduced.

The initial Beta mutation was not counted as a deliberate failure. It was retained as a valuable
negative-control calibration: the detector did not invent a blocker from a robustness preference.
Gamma was then used as the actual deliberate failure without changing the behavioral contract.

## Evaluator scoring after disclosure

The evaluator-only key maps Alpha to the acceptable S01 shape and Gamma to the deliberate
unconditional stale-write defect. The blind detector found the defect and did not report a false
positive for Alpha or the non-defective Beta mutation. Delta remains acceptable for the stated
S01 ordering contract, with lifecycle evidence explicitly unverified. Generation quality and
detection quality are recorded separately; no combined score is emitted.
