## Change contract

- A structured diagnostic keeps only bounded issue type, optional target, repository-relative source
  path, external-source fact, and the concurrency classification.
- External, dependency, generated, and non-selected-target diagnostics stay outside the first-party
  claim; a selected-target diagnostic without authenticated compiler membership is `BLOCKED`.
- Any authenticated first-party warning is treated as new because no warning baseline is inferred.
  A concurrency-only set uses the dedicated `QC.CONCURRENCY.DIAGNOSTICS` terminal outcome; a mixed
  first-party set remains `QC.BUILD.FIRST_PARTY_WARNINGS`.
- Warning, attribution, and concurrency failures never carry evidence or a normal `PASS` verdict.
