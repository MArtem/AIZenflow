## Scope and status vocabulary

This is a closure and traceability audit of the documented system and the evidence already
collected. It does not re-run the 67 archive sources, build an app, run tests or Simulator, invoke
CI, change a consumer, or promote QualityControl. The 67 archive decisions and their hashes were
already independently checked; this block verifies that their decisions remain connected to the
current roadmap, receipts, pins, and explicit gates.

- **fixed** — the finding's documented contract or bounded implementation exists and has direct
  evidence in the cited receipt.
- **accepted** — the proposed ZIP behavior is intentionally rejected or a bounded limitation is
  explicitly retained; no unsafe implementation is silently adopted.
- **deferred** — the required consumer, runtime, adoption, or release evidence is still missing.
- **not applicable** — the finding does not apply to the current scoped artifact; none of F01–F24
  is classified this way in this audit.

“Fixed” is always scoped. It does not mean that every existing worktree or future product has
adopted the rule, and it does not imply a production or release claim.
