zero. `initial result` is the result before any reviewer correction. `missed P1/P2` and
`reviewer corrections` stay separate from ordinary clarification. This table is not telemetry and
does not promise statistical significance.

| user questions | count and reason; product uncertainty is distinct from missing context |
