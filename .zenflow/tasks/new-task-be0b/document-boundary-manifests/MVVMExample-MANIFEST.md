# MVVMExample Documentation Boundary

## Scope
This folder contains only MVVMExample-specific documentation.

Allowed here:
- MVVMExample local rules and exceptions;
- MVVMExample plans, handoffs, ADRs, audits, histories, and reports;
- MVVMExample app-specific prompts or skills;
- MVVMExample remediation specs and local verification decisions.

Not allowed here:
- reusable/global rules unless copied only as explicit app-local reference;
- documentation for Tchop, BattleshipGame, AIFieldbook, or future apps;
- architecture-catalog content that is not MVVMExample-specific.

Local MVVMExample exceptions must stay here unless explicitly promoted to reusable through `DOCUMENT_BOUNDARY_STANDARD.md`.
