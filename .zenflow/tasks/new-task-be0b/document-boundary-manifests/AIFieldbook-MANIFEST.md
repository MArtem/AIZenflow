# AIFieldbook Documentation Boundary

## Scope
This folder contains only AIFieldbook-specific documentation.

Allowed here:
- AIFieldbook local rules and exceptions;
- AIFieldbook plans, handoffs, ADRs, audits, histories, and reports;
- AIFieldbook app-specific prompts or skills;
- AIFieldbook product contract, AI/App Intents decisions, local-only privacy decisions, and verification gates.

Not allowed here:
- reusable/global rules unless copied only as explicit app-local reference;
- documentation for Tchop, MVVMExample, BattleshipGame, or future apps;
- generic AI/iOS rules that are app-neutral and belong in `reusable/`.

Local AIFieldbook exceptions must stay here unless explicitly promoted to reusable through `DOCUMENT_BOUNDARY_STANDARD.md`.
