# iOS Performance Audit Prompt

```markdown
Проведи iOS performance audit.

Используй ios-performance-profiler. Определи реальные пользовательские пути приложения
и выбери приоритетные сценарии по влиянию, известной частоте, риску и вопросу
измерения. Учитывай применимые launch, SwiftUI/render, lists, media, main-thread,
memory/cache, visual effects и database, network или file paths; не предполагая,
что каждая функция присутствует. Предложи подходящий доступный метод и используй
runtime диагностику только при действующих отдельных разрешениях. Статика не
доказывает измеренную производительность.

Вывод: приоритет и причина, сценарий, метод, фактическое evidence и метрики отдельно
от гипотез, findings P0–P3, заблокированные/неизмеренные области, remaining risk и
наименьшее полезное следующее разрешённое действие.
```
