# Local Exception ADR Template

## Purpose
Use this template when a project intentionally violates or narrows a reusable/global rule.

Local exceptions are app/task-specific by default. They do not weaken reusable rules unless the user explicitly approves promotion and the text is rewritten app-neutrally.
