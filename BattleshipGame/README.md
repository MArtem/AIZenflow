# BattleshipGame

Simple SwiftUI iOS Battleship game against the computer.

## How to play

1. Place your ships on the upper board.
2. Use the rotate button to switch horizontal or vertical placement.
3. Press Start after all ships are placed.
4. Fire at the enemy board. The computer fires back automatically.
5. Sink all enemy ships to win.

## Project

- Independent iOS project.
- No external dependencies.
- Main target: `BattleshipGame`.
- Minimum deployment: iOS 17.
